# Установка

Только arm64-v8a (проверено на Galaxy S22+).

1. Скачайте APK: из Releases (`Vita3K-PKGj-*.apk`) или из артефакта сборки в Actions (распакуйте zip, внутри `app.apk`).
2. Откройте файл на телефоне. При запросе разрешите установку из этого источника (Настройки → Приложения → Особый доступ → Установка неизвестных приложений).
3. Первый запуск: выдайте доступ к хранилищу и уведомлениям. Для фоновых загрузок отключите оптимизацию батареи (кнопка в настройках приложения).
4. PKGj уже внутри, откройте его из списка приложений.

## Обновление
- Debug/reldebug-сборки (id `.debug`) ставятся поверх друг друга.
- Release-сборка подписана другим ключом и имеет другой id: она устанавливается отдельно, данные не переносятся автоматически. Копируйте папку данных эмулятора вручную, если нужно.
- Версию сборки смотрите в `device-info.txt` внутри логов сессии.
