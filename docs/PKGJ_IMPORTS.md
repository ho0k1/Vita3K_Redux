# Что PKGj просит у эмулятора

Снято с реальной сессии PKGj на S22+ (сборка `75548dd`, 112 с, список игр, загрузка, выход в игру). Источник: блок `[CALLS:session-end]` в `sessions/pkgj_*.log`. Таблицу можно обновлять новыми логами.

## Итоги

- 187 разных функций, 66,8 млн вызовов. 89% это `SceGxm` (отрисовка интерфейса), дальше `SceLibKernel` (мьютексы, TLS).
- **`SceHttp` PKGj не вызывает совсем.** Сеть идёт через `SceNet` (сокеты, 6035 вызовов). Поэтому заглушки `SceHttp` для PKGj не нужны, пункт из плана снят.
- Ошибок, которые мешают работе, в этой сессии нет. Большая часть «error-like» в старых отчётах была ложной: функции, возвращающие указатели (`sceClibMem*`, `sceClibStr*`, `sceKernelGetTLSAddr`), попадали в счётчик. С версии после `75548dd` они не считаются.
