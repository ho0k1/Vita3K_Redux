## Vita3K Redux 1.2.3

Неофициальный форк Vita3K Plus для Android (arm64-v8a). Интерфейс только на русском.

**Что нового**
- Встроенный PKGj перекрашен в цвета приложения: тёмно-синий фон, бирюзовый акцент, новый фон меню.

**Из 1.2.2**
- Пресет «Режим разрешения» сам ставит анизотропную фильтрацию: Производительность 1,5× → 2×, Баланс 2× → 8×, Качество 2,5× → 16×. «Свой» фильтрацию не меняет.

**Из 1.2.1**
- Тёмная тема в цветах логотипа, новая иконка.
- Звуковые потоки не блокируют ядра гостя — нет внезапных провалов FPS.
- Адаптивное разрешение учитывает загрузку GPU.
- Экран «Патчи игр» удалён.

Игры и прошивка в приложение не входят. Скачайте APK ниже и поставьте поверх; данные сохраняются.
