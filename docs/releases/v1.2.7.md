## Vita3K Redux 1.2.7

**Что нового**
- Проверка обновлений. При запуске приложение смотрит последний релиз на GitHub и, если вышла новая версия, один раз предлагает открыть страницу релиза («Открыть страницу загрузки» или «Отмена»). Для каждой версии вопрос задаётся один раз. Вручную: меню списка игр → «Проверить обновления». Отключить проверку при запуске: Настройки → «Эмулятор» → «Проверка обновлений».
- Переключатель «Стабильная производительность» (Настройки → «Эмулятор», по умолчанию выключен). Система держит ровную частоту чуть ниже максимума, чтобы телефон не перегревался и не сбрасывал частоты резко. Применяется при следующем запуске игры; поддерживается не на всех телефонах.
