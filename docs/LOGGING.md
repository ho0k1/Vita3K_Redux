# Система логов (сессионные логи)

Цель: после любого сбоя, зависания или странного поведения иметь точную историю, не засоряя память телефона.

## Три вида сессий

| Файл (`<папка эмулятора>/sessions/`) | Что в нём |
|---|---|
| `emulator_<время>.log` | Состояние эмулятора **до** запуска приложений: инициализация, прошивка, драйвер GPU, установки. После выхода из игры сюда же дописывается состояние «после игры» |
| `app_<время>_<TITLEID>.log` | Одна запущенная игра: загрузка модулей, вызовы, ошибки, завершение |
| `pkgj_<время>_PKGJ00000.log` | То же для PKGj (сеть, скачивание, установка) |

**Ротация:** для каждого вида хранятся 3 последних файла, более старые удаляются при старте новой сессии. Один файл не больше 48 МБ. Общий лог `vita3k.log` остаётся как раньше (дописывается, ограничен 30 МБ).

В начале и в конце каждой сессии пишется снимок состояния (`[STATE:start]`, `[STATE:end]`, `[STATE:after-app]`): память, RSS процесса, число потоков, загрузка, температуры зон (по ним видно троттлинг).

## Кнопка сохранения

Настройки, раздел **Debug**, пункт **Logs**: кнопка «Save logs to Downloads (zip)». Создаёт `Download/Vita3K-logs-<время>.zip` с `vita3k.log`, `sessions/*.log` и `device-info.txt` (модель, Android, SoC, версия эмулятора).
